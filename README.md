# Superstore Sales & Profit Dashboard

An interactive Power BI dashboard analyzing sales, profit, orders, and product performance using the Superstore dataset (Kaggle, 2026).

## Technologies

Power BI, Power Query, DAX, Excel/CSV

## What I Did

- Built an interactive Power BI dashboard analyzing sales, profit, orders, and product performance
- Cleaned and transformed data using Power Query
- Created DAX measures for Total Sales, Total Profit, Total Orders, and Profit Margin
- Built interactive charts and slicers to explore trends by category, region, and product
- Designed KPI cards and filters for easy business insights

## Dataset

Superstore dataset from [Kaggle](https://www.kaggle.com/) (2026)

## How to Use

1. Clone this repo
2. Open `Superstore.pbix` in Power BI Desktop
3. Use the filters/slicers to explore the data
